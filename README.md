# AI-Based Student Proposal Analysis and Recommendation System

## Overview

This project is a Streamlit-based web application that analyzes student project proposals and provides recommendations.

## Features

- Accepts student project proposals
- Detects project domain
- Identifies possible technologies
- Estimates proposal difficulty
- Generates a proposal score
- Recommends improvements
- Allows report download

## Technologies Used

- Python
- Streamlit
- Rule-based NLP
- Git and GitHub
